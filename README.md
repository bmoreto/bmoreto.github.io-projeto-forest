# 🌲 Forest Project

A responsive and modern website built with **Tailwind CSS v4**, applying **utility-first principles** and **custom styling** through `@apply`.

## 🚀 Overview

This project was developed as part of the **Tailwind CSS course by Origamid**, focusing on mastering responsive layouts, customization, and efficient styling.

Through this project, I explored:
- 🎨 Theme and color customization  
- ✨ CSS animations using Tailwind  
- 🧩 Layouts built with Flexbox and Grid  
- 📱 Best practices for responsive design and file organization  

## 🧠 Learnings

During the course, I deepened my understanding of:
- Core CSS concepts: Box Model, Grid, and Flexbox  
- Tailwind’s **utility-first** workflow  
- Extending Tailwind with **custom classes** and **modifiers**  
- Writing **clean, scalable, and maintainable code**  

## 🛠️ Technologies Used

- HTML5  
- Tailwind CSS v4  
- Flexbox & CSS Grid  
- Responsive Design
